# RTK & Agent Instructions - Frontend Repository

Always prefix CLI commands with `rtk` (e.g. `rtk pnpm install`, `rtk vitest`, `rtk playwright test`).

## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### UAT & Testing standards

Acceptance criteria & Gherkin UAT specifications (`@e2e` tags, Given/When/Then). See `docs/agents/uat-standards.md`.

### Vue Frontend stack

Vue 3 Composition API (`<script setup>`), Feature-Slice architecture, Tailwind Cinema-Glass, Axios services, Toast system and resilient error handling. See `.agents/skills/vue-frontend-stack/SKILL.md`.

### Frontend E2E testing

Headless UAT execution via Docker Compose and Playwright. See `.agents/skills/frontend-e2e-tester/SKILL.md`.
