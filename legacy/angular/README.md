# Angular Legacy — Referenzimplementierung

Diese Angular-App ist die ursprüngliche Implementierung der Filmkritiken-Plattform.

**Nicht löschen vor Abschluss von Phase 3** (Feature-Parität mit der Vue 3 App).

## Hinweise

- Das Vue 3 Projekt liegt im Repository-Root.
- Die Angular-App wird **nicht** aktiv weiterentwickelt.
- Sie dient ausschließlich als Referenz für Implementierungsdetails.

## Starten (lokal, falls nötig)

```bash
cd legacy/angular
npm install
npm start
```
